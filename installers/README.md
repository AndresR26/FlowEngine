🇪🇸 Los instaladores **no se suben** al repositorio (la licencia gratuita de Npcap no permite redistribuirlo). Descárgalos de las páginas oficiales y colócalos **junto a `FlowEngine.exe`** con estos nombres exactos, que son los que busca el programa:
🇬🇧 Installers are **not committed** (the free Npcap licence does not allow redistribution). Download them from the official sites and place them **next to `FlowEngine.exe`** with these exact names, which the program looks for:

| Archivo / File | Fuente oficial / Official source | Obligatorio / Required |
|---|---|---|
| `npcap-1.88.exe` | https://npcap.com/#download | ✅ Windows |
| `nmap-7.99-setup.exe` | https://nmap.org/download.html | Opcional / Optional |

⚠️ Al instalar Npcap marca **"Install Npcap in WinPcap API-compatible Mode"**. / When installing Npcap tick **"Install Npcap in WinPcap API-compatible Mode"**.
